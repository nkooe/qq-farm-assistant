# 自家农场性能优化与采样

程序版本：`1.15.02.006`（npm `1.1502.6`）。本次集中处理自家农场的页面更新和读取调度。

## 实现

- 土地快照保留服务端原值，记录接收时的 `performance.now()`。单个面板共享一个时钟，由卡片计算剩余时间，避免每秒修改全局土地数组。
- 成熟期限按时间排序，游标只处理已经跨越的期限。选地资格随快照、动作类型和成熟边界更新；筛选没有改变已选名单时，复用原数组。
- 倒计时归零显示“待刷新确认成熟”，停止允许施肥；收获资格继续等待服务端快照确认。
- 页面隐藏时停止倒计时和轮询，关闭未执行确认；返回时按实际经过时间校准并刷新。已开始的请求可以完成，隐藏期间不开始后续土地读取。
- 轮询在当前刷新结束 60 秒后开始下一次，慢请求不会堆叠。同账号普通读取共享未完成的请求；返回页面遇到旧读取时，等待结束后再读取新快照。
- 操作完成后强制读取一次新快照，避免复用操作前请求；移除全场操作在 store 和面板各读取一次的重复。隐藏期间完成的操作延后核对，不自动重放。
- 旧账号、旧代次的成功或失败响应不覆盖新快照。操作前开始的手动刷新不能解除操作后的“结果未确认”限制，仍需用户刷新核对。

相关代码：`web/src/composables/useFarmClock.ts`、`web/src/components/FarmPanel.vue`、`web/src/components/FarmLandCard.vue`、`web/src/stores/farm.ts`。

## 浏览器对比

2026-10-21，Chromium 桌面、64 块种植土地、普通肥全选，使用真实生产组件与模拟 API。通过 Vue 组件更新钩子计数，以 Playwright 时钟推进时间；旧版为提交 `9c98a1e54ab832272abaa580566794b12a981a37`（`1.15.02.005`）。

| 观察项 | 1.15.02.005 | 本次优化 |
| --- | ---: | ---: |
| 可见状态推进 10 秒，父面板更新次数 | 10 | 0 |
| 隐藏状态推进 125 秒，父面板更新次数 | 129 | 0 |
| 隐藏状态推进 125 秒，土地读取次数 | 2 | 0 |

卡片在可见状态仍每秒更新倒计时。旧版隐藏期间的更新次数包括两个模拟轮询响应引起的更新，因此高于 125。本结果说明页面的更新和请求减少，不能换算为整机 CPU 降幅，也不是完整浏览器能耗测量。

## 线上自然负载基线

测量区间：2026-10-21 03:18:41–03:28:41 UTC（北京时间 11:18:41–11:28:41），持续约 600 秒，每 15 秒采样，共 41 组。被测版本为升级前的 `1.15.02.005`，两个账号在线；另两个原有失败账号保持失败。

采样器只读取本机缓存状态及容器 cgroup 计数，不触发土地或其他游戏操作。CPU 统计跳过首组，100% 表示一个 CPU 核；内存包含容器文件缓存；接口延迟为同容器回环 HTTP。

| 指标 | 结果 |
| --- | --- |
| 容器 CPU 中位数 / P95 / 最大值 | 1.02% / 1.64% / 2.04% |
| 容器内存最小值 / 中位数 / 最大值 | 158.36 / 162.28 / 167.79 MiB |
| 状态接口延迟中位数 / P95 / 最大值 | 2.33 / 5.90 / 18.56 ms |
| 状态读取错误 | 0 |
| 原在线账号 | 两个账号各组采样均保持在线 |
| 日志标记 | 心跳超时、ACK 超时、登录中止、连接或握手失败、初始化失败均为 0 |

这是服务器的短时基线，并非前端优化带来的服务端性能提升。日志按采样起点读取，结束附近可能包含少量额外观察时间。10 分钟观测不能证明没有内存泄漏或长期掉线；当前数据也没有支持提高游戏请求并发的必要。

## 重复采样

在服务器项目目录运行，Node.js 20+，容器名按实际修改：

```sh
docker exec -i qq-farm-bot node - 600 15 < scripts/sample-runtime.cjs > runtime-samples.jsonl
```

PowerShell：

```powershell
Get-Content -Raw scripts/sample-runtime.cjs | docker exec -i qq-farm-bot node - 600 15 > runtime-samples.jsonl
```

脚本通过容器内回环地址创建采样会话，令牌只存内存，正常结束或捕获错误后注销；输出仅含账号 ID、运行/连接状态、耗时和资源计数。cgroup 不可读的资源项输出 `null`。可将时长增加到 3600 秒观察更长趋势，间隔仍用 15 秒。
