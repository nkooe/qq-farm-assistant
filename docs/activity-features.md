# 活动、节令、图鉴与背包扩展

入口：底部导航“活动”，进入后可切换“活动大厅 / 节令日历”；图鉴和背包沿用原有入口。

## 功能

| 页面 | 内容 |
| --- | --- |
| 活动大厅 | 当前账号的活动目录、开放状态、时间、按需加载详情 |
| 节令日历 | 节令奖励、节令答题、季度点亮进度和集齐奖励 |
| 赛季活动 | 千星游记、观星礼录、星砂商店、节令兑换 |
| 其他活动 | 奶茶经营与打工、萌宠日记、秋祈良愿、快乐不独享、雨落成诗、鹊桥寄情、公益小红花、青梅酿造 |
| 图鉴 | 收集等级、等级奖励、变异分类（普通 / 装扮 / 活动）、属性加成；保留原有种子补录购买 |
| 背包 | 按 UID 独立展示物品堆、锁定 / 解锁、到期提示、变异标签、条件出售保护 |

活动大厅只展示当前账号正在开放的活动，已结束、未开始或时间未确认的记录不展示；页面停留期间到期的卡片会自动移除。开放时间以游戏服务器时间和活动窗口为准。协议暂不支持的活动不会被强行启用。答题由用户选择答案，后台不会自动猜题。

背包手动与自动出售使用同一检查：锁定堆跳过，未知或过期的活动时间缓存不能解锁条件出售。锁定与出售按账号串行执行，出售前重读库存；同名多堆要求 UID，禁止重复 UID 或超库存数量。网络超时不会触发立即重放出售。

领取类操作重读资格，避免重复提交。领取成功后刷新失败仍保留实际奖励，并提示刷新确认。应用宝、代理、启动脚本与登录协议不因这些活动功能改变。

## 1.15.02.007 补齐

### 奶茶自动领取

旧版奶茶只有页面与手动接口，没有接入 Worker 定时器，所以页面能看到收益，后台仍不会领取。本版新增每账号 `milk_tea` 开关，默认开启；登录或开启后约 15 秒首次检查，之后每 5 分钟领取营业收益、工作工资及已解锁成长基金奖励。活动未开放、结束或尚未开业时每 30 分钟检查；手动开业成功后重新安排首次检查。

后台不依赖浏览器页面。断线、停止、账号同步时暂停。自动与手动写操作共用队列，发送前重新检查资格和当前连接轮次；超时或回包不完整不立即重放，下一轮先读取服务器状态，已确认的部分成功仍会显示。状态通过现有账号状态推送到奶茶页面。

需先手动开业。制作、雇佣、爆单、购买、升级、付费解锁与打工互动仍由用户决定，自动领取不会代替用户消费资源。页面可能在下一次手动刷新前仍显示旧库存，是否领取以自动任务结果及服务器最新进度为准。

### 土地与节令

土地卡片的“详情”显示当前／下一等级加成、解锁前置土地、角色等级及资源费用，不执行升级。运行协议修正 `LandUnlockCondition` 的前置土地／等级／金币字段，以及 `LandUpgradeCondition` 的条件类型／条件值／物品列表。服务器当前加成和费用优先，缺少字段时使用静态配置并提示未知条件；大额费用保持字符串精度，余额不完整时显示待同步。

节令只对存在已校验答案索引的题目标注“正确答案”；缺失、越界或未知题目返回空索引，仍由用户手动提交。

土地配置与五张土地图片参考 [liyangpengs/qq-farm-bot](https://github.com/liyangpengs/qq-farm-bot) 提交 `e5f3552612cde30e2a58550665a816d3775f71d6`，重阳／霜降答案参考 `57cddb3801987ee6549242e56befef13eaf52fdd`（ISC；游戏图像与配置原权利归属不变）。奶茶调度、账号隔离、状态开关与回归测试为本项目接入实现。

## 接入位置

- `core/src/modern/`：扩展协议独立 Protobuf Root、活动服务、元数据及资源，与主运行协议独立加载；土地解锁／升级条件已按完整协议修正。
- `modern/utils/network.js`：复用账号 Worker 的现有连接，不建立第二个游戏会话。
- `modern/feature-api.js`：Worker 调用白名单。
- `controllers/admin-modern-feature-routes.js`：HTTP 路由；所有入口检查账号归属和在线状态。
- `services/warehouse.js`：原调用接口转发到带锁定和条件检查的仓库实现，自动任务也受保护。
- `web/src/views/Activities.vue`：账号切换、活动与节令导航、现有亮暗主题适配。
- `web/src/components/illustrated/CollectionProgress.vue`：图鉴等级、分类及奖励。
- `web/src/components/BagPanel.vue`：UID 选择、锁定、到期与出售提示。

活动状态写入现有数据目录下各账号独立的 `activity-center-state-*.json`，继续遵循 `FARM_DATA_DIR`。参考项目中的账号库、凭据、日志与缓存没有迁入。

## 来源

本扩展根据用户提供的本地 `qq-farm-bot-master` 源码（其 `core/package.json` 声明 ISC）适配活动服务、协议、界面、配置与图像资源。服务的 TypeScript 机械转换为本项目使用的 CommonJS，新增账号权限、独立协议加载、旧接口适配和出售保护。相应源码顶部保留来源说明。图像与游戏配置的原权利归属不变。
