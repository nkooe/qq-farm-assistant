# 1.15.02.005 土地选地操作

自家农场使用独立土地卡片。合种主地与副地各自显示，点击任一地块会同步选择同一株作物，执行时只提交主地一次；好友土地界面继续使用原组件。

## 使用

1. 进入在线账号的农场，点击“选地普通肥”“选地有机肥”“选地务农”“选地收获”或“选地铲除”。
2. 点击土地，或用 Tab 聚焦后按 Enter / Space；也可以“全选可用”“清空”“退出选地”。灰色提示说明不可选原因。
3. 点击“对所选…”核对账号和主地名单，再确认执行。合种按作物株数计数，铲除不可恢复。
4. 普通肥、有机肥均为每株施肥一次。有机肥受剩余次数限制，不会循环消耗肥料。全场操作保持在单独一组按钮中。

## 土地布局

农场网格按可用宽度自动增加列数，桌面最多七列，避免图块过宽或过密；手机保持两列。作物图缩为 36 像素，土地类型与季数或合种关系同排显示，空间不足时换行；无变异或务农提示时不占用额外状态栏。

详情、催熟和铲除按钮仍保留至少 44×44 像素的点击区域。倒计时、进度、合种关联和异常提示均保留，选地、确认弹窗及游戏操作流程保持一致。

## 接口与结果

`POST /api/farm/selected` 使用现有登录凭据与 `x-account-id` 权限控制，请求示例：

```json
{ "action": "fertilizeNormal", "landIds": [1, 5] }
```

`action` 支持 `fertilizeNormal`、`fertilizeOrganic`、`clear`、`harvest`、`remove`。`landIds` 必须为 1–64 个正安全整数的数组，缺失、空数组及混合类型均拒绝，不会回退为全场。

每次执行前读取最新土地，检查解锁、生长阶段、务农需求及有机肥剩余次数，映射合种主地并去重。选地收获显式使用 `is_all=false`。每账号 Worker 同时只接受一个选地操作，锁在失败后释放。

回包包含成功、跳过原因、失败和未确认名单，成功数仅按服务端返回地块计算。施肥回包按 1.15 的 `corepb.Item fertilizer` 与逐地 `land_op_drops` 解码，显示剩余肥料和已知消耗秒数。未返回计数时不猜测数值。

网络中断、超时或部分地块未获确认时不自动重试。界面保留仍有效的失败选择，并要求手动刷新、核对结果后才能再次操作。自动刷新不会解除这一限制。账号切换或断线关闭未执行的确认，已提交操作仍归属原账号，迟到结果不能覆盖另一账号页面。同账号土地请求也按请求代次隔离，刷新失败保留上一次快照。

这不是事务性操作：游戏状态可能随自动化变化，服务器会按收到请求时的状态裁定。刷新只能核对当前土地，不能证明中断请求一定没有消耗资源。
