## 升级与核验

源码运行先备份 `core/data/` 及应用宝数据库，再运行：

```bash
pnpm install --frozen-lockfile
pnpm build:web
pnpm -C core test
```

Docker 运行 `docker compose up -d --build`；既有数据卷继续使用。启动后登录页显示两个版本，公开的 `/api/game-version` 返回游戏版本；带现有管理员鉴权请求 `/api/ping` 返回程序显示版本。健康检查同时覆盖主程序和应用宝，确认原运行账号恢复连接。

如需回退，保留旧镜像和升级前的持久化数据备份；回退前先停止目标容器，恢复对应镜像与配置，再使用原 Compose 配置启动。

ACEVM 等浏览器专用能力仍受 Node.js 宿主限制，未执行的检查返回失败并记录告警，不能由离线测试推断长期在线稳定性。
